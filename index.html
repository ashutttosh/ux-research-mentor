What it does

11 skills, one mentor

Every skill activates on natural language — just describe what you're trying to do. No commands to memorize.

🗺️

Plan a research study

plan-research-study

Pick the right method (interviews, surveys, usability, diary, A/B), write the plan, brief stakeholders.

🎙️

Conduct interviews

conduct-interviews

Five-block interview guides, Mom Test principles, moderation craft, structured note-taking.

📋

Design a survey

design-survey

Questionnaire structure, scale choice, sampling methods, sample-size planning.

🔍

Usability testing

usability-testing

Moderated and unmoderated test plans, task scripts, NN/g-style severity scoring.

📔

Diary studies

diary-studies

Longitudinal study setup, prompt design, monitoring, exit interviews, analysis.

🧩

Analyze research

analyze-research

Thematic analysis, affinity mapping, large-scale group analysis, GDS workshop format.

📊

Quant UX research

quant-ux-research

SUS, SEQ, NPS, benchmarking, confidence intervals, sample-size cheat sheet.

🤖

AI research workflow

ai-research-workflow

Caitlin Sullivan's Claude Code for Customer Insights approach + Saeideh Bakhshi's quant toolkit.

♿

Accessibility research

accessibility-research

Inclusive recruitment, AT-aware moderation, AR/spatial UX research.

⚙️

Research ops

research-ops

Participant recruitment, repositories, templates, governance, the four ReOps pillars.

🎯

UXR career coach

uxr-career-coach

Career transitions, job search, mentorship, salary benchmarks, negotiation tactics.

Install

Two minutes to install

Works with Cowork (Claude desktop app) and Claude Code. Both use the same plugin format.

1

Download the plugin

Get ux-research-mentor.plugin — it's a 75 KB zip.

⬇ Download
2

Install in Cowork or Claude Code

Cowork: Settings → Plugins → Install from file → pick the .plugin file.

Claude Code: drop the unzipped folder into your plugins directory and restart.

3

Trigger a skill

Just describe what you need:

"Plan a usability test for our new
checkout flow"

"What's a fair UXR salary for L5
at Google?"

"Help me transition from academia
to UXR"
