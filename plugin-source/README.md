# UX Research Mentor

A Cowork / Claude Code plugin that turns Tarah Srethwatanakul's **UX Research Resource Guide** (bit.ly/UXRguide, last updated April 2026) into a working assistant.

## What it does

Eleven skills covering the methodologies and career paths the guide references — from picking the right method, to running the study, to landing the job:

| Skill | Triggers when you ask about… |
|---|---|
| `plan-research-study` | Which method to use, writing a research plan, briefing stakeholders |
| `conduct-interviews` | Interview guides, Mom Test, moderation, note-taking |
| `design-survey` | Survey design, sampling methods, quant questionnaires |
| `usability-testing` | Moderated/unmoderated tests, scripts, scoring |
| `diary-studies` | Longitudinal research, diary studies |
| `analyze-research` | Synthesis, affinity mapping, large-scale group analysis |
| `quant-ux-research` | Statistics, benchmarking, behavioural metrics |
| `ai-research-workflow` | Using AI (Claude, GPT) for customer research analysis |
| `accessibility-research` | Inclusive research, recruiting disabled participants |
| `research-ops` | Participant recruitment, repositories, templates, ReOps |
| `uxr-career-coach` | Career transitions, job search, mentorship, compensation, negotiation |

## Install

Copy this folder (or the `.plugin` archive) into your Claude Code / Cowork plugin directory and restart.

## Source

Built entirely from **The UX Research Resource Guide** maintained by Tarah Srethwatanakul — a Staff Researcher with 10+ years across fintech (Monzo), big tech (Meta), and independent consulting. The original is at bit.ly/UXRguide; this plugin is a derivative work that organizes those recommendations into a skill-driven assistant.
